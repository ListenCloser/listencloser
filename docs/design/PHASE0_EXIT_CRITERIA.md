# Phase-0 exit criteria

Owner: #1143

Phase 0 is complete only when all of the following are true:

- current-main visual census is complete;
- current screenshot baseline/state coverage is mapped;
- candidate open tools have primary-source setup/license/adoption notes;
- first reference corpus exists with at least four deep design-DNA analyses completed;
- fixed visual brief and scorecard are stable enough to compare tools fairly;
- first signed-out landing experiment can be run without modifying production semantics;
- no historical visual thesis has been promoted merely by default;
- no third-party tool has been installed as a normal repo dependency without evidence it improves the workflow.

Phase 0 does **not** require:

- selecting the final brand;
- merging a new favicon;
- redesigning the landing;
- changing workspace colors;
- adopting an external component system.

After Phase 0, proceed to divergent rendered proposals under the same #1143 owner unless current ownership changes.
