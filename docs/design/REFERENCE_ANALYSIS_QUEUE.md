# Reference-analysis execution queue

Owner: #1143

This queue turns the V0 corpus into bounded research work. It is intentionally ordered to maximize contrast rather than similarity.

## Wave 1 — four contrasting systems

Analyze these first using `DESIGN_DNA_TEMPLATE.md`:

1. **Ableton Live** — specialist creative-tool density, stable time/canvas model.
2. **NYT interactive/editorial work** — typography-led explanation and integrated graphics.
3. **Teenage Engineering** — ownable music-tech personality without generic AI language.
4. **Figma** — quiet application shell, canvas dominance, contextual inspector.

Goal: identify design decisions that remain useful when the references disagree aesthetically.

## Wave 2 — interaction / micro-craft

5. **Raycast** — compact typography, icons, keyboard-oriented hierarchy.
6. **Linear** — micro-consistency and dense application chrome; explicitly flag now-generic `Linear-like` tropes.
7. **Moises** — musician-facing analysis-to-action hierarchy.
8. **Observable** — evidence/visualization integrated into explanation.

Goal: find reusable interaction/craft decisions without averaging into generic productivity SaaS.

## Wave 3 — identity / content relationship

9. **Bloomberg** — strong information identity through typography/color under density.
10. **A24** — restrained parent identity while content carries expression.
11. **Hooktheory TheoryTab** — music itself as synchronized explanatory content.
12. **Historical Listen Closer #706/#405** — run our own prior direction through the same template instead of granting incumbent authority.

Goal: test how much brand character should live in shell vs musical content vs marketing surface.

## Output rule

Every completed analysis must end with:

- 3–5 transferable decisions;
- 2–5 explicit `do not copy` items;
- at least one testable Listen Closer hypothesis;
- fit by landing / workspace / Breakdown / favicon;
- `REFERENCE`, `DEEP REFERENCE`, `CONTRAST`, or `DROP` status.

Do not add a reference solely because it is visually attractive.
