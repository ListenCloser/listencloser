## 5. Melody Engine: `SkylineMelodyEngine`

**File:** `backend/engines/melody/skyline_engine.py`

### Entry Point: `analyze(midi_bytes)` → `MelodyResult`

### Algorithm: `_midi_melody()` (L54-117)
1. Flatten all non-drum notes across instruments
2. Sort by onset, then pitch (descending)
3. Group notes within 30ms onset windows → "simultaneous" candidates
4. For each window, score candidates by:
   - Duration (sustained preferred, capped at 2s) — weight 0.5
   - Leap from previous note (small preferred) — weight 0.4
   - Pitch height (higher preferred) — weight 0.1
5. Pick best candidate; track score margin vs runner-up
6. Compute aggregate stats on resulting line

### Output Features:
- `low_pitch`, `high_pitch`, `range_semitones`
- `unique_pitch_classes`
- `stepwise_ratio` (interval ≤ 2 semitones)
- `leap_ratio` (interval ≥ 5 semitones)
- `quality_score` = mean margin (best - 2nd best) / capped to [0,1]
- `heuristic`: `"greedy_continuity_skyline"`

### Provenance:
```python
EngineProvenance(engine="skyline", library_version=pretty_midi.__version__, parameters={"heuristic": "greedy_continuity_skyline"})
```

## 6. Rhythm Analysis: `_midi_rhythm()`

**File:** `backend/analyze.py:165-204`

### Input: Performance MIDI (pretty_midi)
### Output: `RhythmResult`

### Computation:
- `beat_count` = duration × median_tempo / 60 (from MIDI tempo metadata)
- `avg_note_duration` = mean(note.end - note.start) across all non-drum notes
- `rhythmic_density` = total_notes / duration
- `syncopation_ratio` = `None` (explicitly NOT computed — requires audio beat grid)
- `syncopation_available` = `False`

### Honest Limitation (Docstring L169-172):
> "Syncopation is NOT computed here: a raw performance MIDI has no trustworthy metrical hierarchy (beat/downbeat) — pretty_midi injects a default 4/4 that is an assumption, not evidence."

## 7. Insight Persistence: `_create_insight()` per Output

**File:** `backend/domain/capabilities.py:195-243`

### Insight Kinds Created (in order):

| Analysis Output | Insight Kind | Method | Confidence | Provenance |
|-----------------|--------------|--------|------------|------------|
| Key | `key` | `detected` | music21 correlation | harmony_provenance["key"] |
| Tempo | `tempo` | `detected` | 0.9 (hardcoded) | — (suppressed if pulse_is_default) |
| Time Signature | `time_signature` | `detected` | 0.9 (hardcoded) | — (suppressed if pulse_is_default) |
| Each Chord | `chord` | `inferred` | `None` | harmony_provenance["chords"] |
| Each Roman Numeral | `roman_numeral` | `inferred` | `None` | harmony_provenance["roman_numerals"] |
| Each Cadence | `cadence_candidate` | `heuristic` | `None` | harmony_provenance["cadences"] |
| Rhythm (aggregate) | `rhythm` | `heuristic` | `None` | — |
| Melody (aggregate) | `melody` | `heuristic` | `None` | melody_provenance |
| Voice Leading | `voice_motion_candidate` | `heuristic` | `None` | harmony_provenance["voice_leading"] |

### Critical Observations:
1. **Chords/RN/Cadences** → `confidence=None` (no calibrated scores)
2. **Tempo/TimeSig** → Hardcoded 0.9 confidence from MIDI metadata (often transcription defaults)
3. **Key** → Only music21 correlation coefficient (not calibrated probability)
4. **Provenance** → Per-component, correctly distinguishes music21 vs custom-rule
