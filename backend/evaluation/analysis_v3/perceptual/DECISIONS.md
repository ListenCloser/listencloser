# Decision rules

A descriptor advances beyond `RESEARCH` only if it demonstrates all of:

1. controlled/synthetic correctness;
2. stability under relevant preprocessing;
3. legible behavior on rights-safe real music;
4. at least one valuable downstream relation from #456/#457;
5. an explicit normalization contract;
6. practical runtime and licensing;
7. safe abstention/withholding semantics.

A descriptor may still be rejected even if numerically correct when it adds little product value or is redundant with stronger evidence.
